## 1. String / StringBuilder / StringBuffer

### String — 不可变字符串

**是什么：** `String` 底层是 `final byte[]`（或 `final char[]`），一旦创建，内容不能改。

**注意：** 所有"修改"操作（`+`、`concat`、`replace`）实际上都创建了**新对象**，原对象不动：

```java
String s = "hello";
s = s + " world";   // 创建了新 String 对象，旧 "hello" 被丢弃
```

**常用方法：**

```java
String s = "hello";

s.length();                    // 长度 → 5
s.charAt(2);                   // 下标 2 的字符 → 'l'
s.indexOf("l");                // 第一个 "l" 的位置 → 2
s.substring(1, 4);             // 截取 [1, 4) → "ell"
s.equals("hello");             // 比较内容是否相等
s.equalsIgnoreCase("HELLO");   // 忽略大小写比较
s.contains("el");              // 是否包含 → true
s.startsWith("he");            // 是否以 "he" 开头
s.endsWith("lo");              // 是否以 "lo" 结尾
s.replace("l", "x");           // 替换所有 → "hexxo"（新对象）
s.toUpperCase();               // 转大写 → "HELLO"（新对象）
s.toLowerCase();               // 转小写
s.trim();                      // 去首尾空格（新对象）
s.split(",");                  // 按逗号分割成 String[]
s.toCharArray();               // 转 char[]
```

### StringBuilder — 可变字符串（单线程用）

**为什么需要：** 频繁拼接字符串时，String 每次创建新对象，浪费内存。StringBuilder 直接在原对象上改，效率高。

```java
StringBuilder sb = new StringBuilder("hello");

sb.append(" world");           // 往后追加
sb.insert(0, "say: ");         // 在指定位置插入
sb.delete(0, 4);               // 删除 [0, 4) 的字符
sb.replace(0, 3, "hi");       // 替换 [0, 3) 为 "hi"
sb.reverse();                  // 反转
sb.length();                   // 当前长度
sb.toString();                 // 转成 String
```

### StringBuffer — 可变字符串（多线程用，synchronized）

用法和 StringBuilder 完全一样，但方法都加了 `synchronized`，线程安全。

### 三者对比

| | String | StringBuilder | StringBuffer |
|---|--------|-------------|---------------|
| 可变性 | 不可变 | 可变 | 可变 |
| 线程安全 | 安全（不可变天然安全） | 不安全 | 安全（synchronized） |
| 速度 | 慢（拼接创建新对象） | 快 | 中 |
| 使用场景 | 常量、少量修改 | 单线程大量拼接 | 多线程大量拼接 |

## 2. Date / SimpleDateFormat

### Date 类（java.util.Date）

```java
import java.util.Date;

Date now = new Date();           // 当前时间
System.out.println(now);         // Tue Jun 02 11:10:00 CST 2026

long millis = now.getTime();     // 毫秒时间戳（1970-01-01 到现在的毫秒数）
```

### SimpleDateFormat — 格式化 & 解析

```java
import java.text.SimpleDateFormat;
import java.util.Date;

// 格式化：Date → 字符串
SimpleDateFormat sdf = new SimpleDateFormat("yyyy年MM月dd日 HH:mm:ss");
String str = sdf.format(new Date());   // "2026年06月02日 11:10:00"

// 解析：字符串 → Date（需要 try-catch 或 throws）
Date d = sdf.parse("2026-06-03 10:30:00");
```

**常用格式符号：**

| 符号 | 含义 | 示例 |
|------|------|------|
| yyyy | 年 | 2026 |
| MM | 月（02 位） | 06 |
| dd | 日 | 02 |
| HH | 时（24小时，2位） | 14 |
| mm | 分 | 30 |
| ss | 秒 | 05 |
| E | 星期 | 星期二 |

## 3. Calendar

**是什么：** 可以**计算**日期的工具类。Date 只能表示一个瞬间，Calendar 可以加减日期。

```java
import java.util.Calendar;

Calendar cal = Calendar.getInstance();     // 获取当前时间

// 获取字段
cal.get(Calendar.YEAR);                    // 年份
cal.get(Calendar.MONTH);                   // 月份（0=1月！实际月份要 +1）
cal.get(Calendar.DAY_OF_MONTH);            // 日

// 设置日期
cal.set(Calendar.YEAR, 2026);
cal.set(Calendar.MONTH, Calendar.JUNE);    // 或用 5（0=1月）
cal.set(Calendar.DAY_OF_MONTH, 2);

// 日期计算
cal.add(Calendar.DAY_OF_MONTH, 10);        // 加 10 天
cal.add(Calendar.MONTH, -1);               // 减 1 个月

// Calendar → Date
Date date = cal.getTime();

// Date → Calendar
cal.setTime(new Date());
```

**注意坑：** `Calendar.MONTH` 值从 0 开始！0=JANUARY，1=FEBRUARY，...，5=JUNE

## 4. Math

所有方法都是静态的，直接用 `Math.xxx()` 调用。

```java
Math.abs(-5);              // 绝对值 → 5
Math.max(3, 8);            // 最大值 → 8
Math.min(3, 8);            // 最小值 → 3
Math.pow(2, 3);            // 2 的 3 次方 → 8.0
Math.sqrt(16);             // 平方根 → 4.0
Math.cbrt(27);             // 立方根 → 3.0
Math.random();             // [0.0, 1.0) 的随机小数
Math.round(3.6);           // 四舍五入 → 4
Math.ceil(3.2);            // 向上取整 → 4.0
Math.floor(3.8);           // 向下取整 → 3.0

// 生成 [0, 100) 的随机整数
int r = (int)(Math.random() * 100);

// 生成 [a, b] 的随机整数
int r = (int)(Math.random() * (b - a + 1)) + a;
```

## 5. BigInteger

**是什么：** 表示**任意大的整数**。`long` 最大约 9×10¹⁸，超过就用 BigInteger。

**注意：** 和 String 一样**不可变**，每次运算返回新对象。

```java
import java.math.BigInteger;

BigInteger a = new BigInteger("99999999999999999999");
BigInteger b = new BigInteger("1234567890");

a.add(b);                  // 加法（返回新对象！）
a.subtract(b);             // 减法
a.multiply(b);             // 乘法
a.divide(b);               // 除法（取整）
a.mod(b);                  // 取余
a.pow(10);                 // 10 次方
a.compareTo(b);            // 比较：-1(a<b)  0(=)  1(a>b)
a.equals(b);               // 值是否相等
a.toString();              // 转字符串
```

## 6. BigDecimal

**是什么：** 表示**精确的任意精度小数**。

**为什么需要：** `double` 和 `float` 有精度问题：

```java
System.out.println(0.1 + 0.2);    // 0.30000000000000004 ← 错的！
```

金融计算（金额、利率）必须用 BigDecimal。

**注意：** 构造**必须用字符串**，`new BigDecimal(0.1)` 还是会有精度问题！

```java
import java.math.BigDecimal;

BigDecimal x = new BigDecimal("0.1");      // ✅ 用字符串构造
BigDecimal y = new BigDecimal("0.2");

x.add(y);                                  // 0.3（精确！）
x.subtract(y);                             // 减法
x.multiply(y);                             // 乘法

// 除法必须指定精度和舍入模式（否则除不尽可能抛异常）
x.divide(y, 2, RoundingMode.HALF_UP);     // 保留 2 位，四舍五入

// 常用舍入模式
// RoundingMode.HALF_UP    — 四舍五入
// RoundingMode.HALF_DOWN  — 五舍六入
// RoundingMode.UP         — 直接进 1
// RoundingMode.DOWN       — 直接舍
```

## 7. 枚举

**是什么：** 值被限定在几个固定选项里的特殊类。枚举的每个值都是**该类型的一个实例对象**。

**为什么需要：** 替代 `int` 常量，编译器能检查值是否合法，可读性好。

### 基础写法

```java
enum Season {
    SPRING, SUMMER, AUTUMN, WINTER
}

// 使用
Season s = Season.SUMMER;
if (s == Season.SUMMER) { ... }       // 可以用 == 比较

// 遍历
for (Season v : Season.values()) {
    System.out.println(v);            // SPRING, SUMMER, ...
}

// 字符串 ↔ 枚举
Season s2 = Season.valueOf("AUTUMN"); // 字符串转枚举
```

### 带属性的枚举

```java
enum Weekday {
    MONDAY("星期一"),
    TUESDAY("星期二"),
    WEDNESDAY("星期三"),
    THURSDAY("星期四"),
    FRIDAY("星期五"),
    SATURDAY("星期六"),
    SUNDAY("星期日");

    private String chineseName;

    Weekday(String chineseName) {         // 构造器（Java 自动加 private）
        this.chineseName = chineseName;
    }

    public String getChineseName() {
        return chineseName;
    }
}

// 使用
System.out.println(Weekday.FRIDAY.getChineseName());  // "星期五"
```

**原理：** `MONDAY("星期一")` 等价于 `new Weekday("星期一")`，只是枚举的实例在定义时一次性创建好，外面不能 new。

### 枚举常用方法

| 方法 | 说明 | 示例 |
|------|------|------|
| `values()` | 获取所有枚举值数组 | `Season.values()` |
| `valueOf(String)` | 字符串转枚举 | `Season.valueOf("SPRING")` |
| `name()` | 获取枚举常量名 | `Season.SUMMER.name()` → "SUMMER" |
| `ordinal()` | 获取序号（从 0 开始） | `Season.SPRING.ordinal()` → 0 |

## 8. 注解

### 是什么

代码里的**标记/标签**，给编译器和工具看，不影响运行逻辑。

### 内置注解

```java
@Override                       // 标记此方法是重写父类的
@Deprecated                     // 标记此方法已过时
@SuppressWarnings("all")        // 关掉编译警告
```

### 自定义注解

```java
import java.lang.annotation.*;

// 1. 定义注解
@Retention(RetentionPolicy.RUNTIME)      // 保留到运行时
@Target(ElementType.METHOD)              // 只能贴在方法上
@interface Log {
    String value();                       // 注解的属性
}

// 2. 使用注解
class Robot {
    @Log("正在吃饭")
    public void eat() { }

    @Log("正在跑步")
    public void run() { }
}

// 3. 通过反射读取注解（运行时）
Method[] methods = Robot.class.getMethods();
for (Method m : methods) {
    if (m.isAnnotationPresent(Log.class)) {
        Log lg = m.getAnnotation(Log.class);
        System.out.println(lg.value());
    }
}
```

### 元注解（给注解加的注解）

| 元注解 | 作用 | 常见值 |
|--------|------|--------|
| `@Target` | 限制注解能贴在哪 | `TYPE`(类), `METHOD`(方法), `FIELD`(字段) |
| `@Retention` | 保留到什么时候 | `SOURCE`(源码), `CLASS`(编译), `RUNTIME`(运行时) |
