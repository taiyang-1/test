### 构造器类型对比

| 类型 | 参数 | 用途 | 示例 |
|------|------|------|------|
| 无参构造器 | 无 | 使用默认值 | `new Student()` |
| 全参构造器 | 所有属性 | 一次性设置所有属性 | `new Student("001", "张三", 20, 95.5)` |
| 部分参数构造器 | 部分属性 | 灵活创建对象 | `new Student("001", "张三")` |
| 配置参数构造器 | 配置信息 | 初始化对象 | `new StudentManager(50)` |
| 链式构造器 | 调用其他构造器 | 避免代码重复 | `this(id, name, 18, 0.0)` |

### this 的使用场景

| 场景 | 语法 | 示例 |
|------|------|------|
| 访问属性 | `this.属性名` | `this.name = name` |
| 调用方法 | `this.方法名()` | `this.show()` |
| 调用构造器 | `this(参数)` | `this(id, name)` |

### static 与构造器

| 特性 | 说明 | 示例 |
|------|------|------|
| static 变量 | 所有对象共享 | `static int count = 0` |
| static 方法 | 属于类，不属于对象 | `static int getCount()` |
| 构造器中访问 | 可以访问 static 和非 static | `count++`, `this.name = name` |

## 🎯 总结

1. **构造器是创建对象时自动调用的特殊方法**
2. **构造器可以有多种用法**：无参、全参、部分参数、配置参数、链式调用
3. **参数不一定是属性**，可以是配置信息、临时数据
4. **同名参数必须用 `this` 区分**
5. **static 计数器是统计对象数量的经典应用**
6. **遵循最佳实践**：提供无参构造器、参数验证、保持简单

**记住：构造器的设计应该让创建对象变得简单、安全、灵活！**
