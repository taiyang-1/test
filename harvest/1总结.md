## T1 方法重载

**核心规则：** 同一个类中，方法名相同，参数列表不同（个数/类型/顺序），与返回值无关。

```java
max(double a, double b)
max(double a, double b, double c)   // 参数个数不同
concat(String a, String b)
concat(String a, String b, String c)
concat(String a, int b)             // 参数类型不同
```

**技巧：** `max(a,b,c)` 内部复用了 `max(a,b)`，避免重复逻辑。

## T2 递归

**核心结构：** 终止条件 + 递归调用

```java
// 阶乘
int factorial(int n) {
    if (n == 1) return 1;          // 终止条件
    return n * factorial(n - 1);   // 递归
}

// 斐波那契
int fib(int m) {
    if (m == 0) return 0;
    if (m == 1) return 1;
    return fib(m-1) + fib(m-2);
}

// 数组求和
int arraySum(int[] arr, int index) {
    if (index < 0) return 0;
    return arr[index] + arraySum(arr, index - 1);
}
```

**注意：** 递归必须有终止条件，否则栈溢出（StackOverflowError）。

## T3 二维数组 — 矩阵转置

**核心：** 转置 = 行列互换，`a[i][j]` → `transposed[j][i]`

```java
int[][] transposed = new int[cols][rows];   // 注意行列要互换
for (int i = 0; i < rows; i++)
    for (int j = 0; j < cols; j++)
        transposed[j][i] = a[i][j];
```

**进阶：** 最终版支持任意 m×n 矩阵（不限于 3×3），用 Scanner 动态输入行列数。

## T4 String 操作

写了 3 个方法：

```java
reverse(String str)          // 字符串反转：toCharArray() + 双指针交换
isPalindrome(String str)     // 回文判断：反转后与原串比较
countChar(String str, char c) // 统计指定字符出现次数
```

**String 常用方法速记：**

| 方法 | 作用 |
|------|------|
| `charAt(i)` | 取第 i 个字符 |
| `indexOf(ch)` | 首次出现位置，没有返回 -1 |
| `substring(start, end)` | 截取 [start, end)，不含 end |
| `equals()` | 比较内容（不能用 `==`） |
| `trim()` | 去掉首尾空格 |
| `replace(old, new)` | 替换字符/子串 |
| `split(",")` | 按分隔符切割成数组 |
| `toCharArray()` | 转成 char 数组 |

## 挑战题：字符频率统计（只用数组）

**关键思路：** char 本质是整数（ASCII 码），可以直接当数组下标。

```java
int[] arr = new int[128];

// 统计：字符 → ASCII → 下标
for (int i = 0; i < str.length(); i++) {
    arr[str.charAt(i)]++;
}

// 输出：下标 → 字符
for (int i = 0; i < arr.length; i++) {
    if (arr[i] > 0) {
        System.out.println((char) i + " 出现 " + arr[i] + " 次");
    }
}
```

**两步转换：**
- 统计时：`'a'` 自动变成 `97`（隐式转换）
- 打印时：`97` 强转回 `'a'`（`(char) i`）
