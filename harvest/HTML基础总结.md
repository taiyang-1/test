## 1. HTML 文档骨架

```html
<!DOCTYPE html>        <!-- 声明这是 HTML5 -->
<html lang="zh-CN">    <!-- 语言属性，帮助读屏器和搜索引擎 -->
<head>
    <meta charset="UTF-8">     <!-- 编码，否则中文乱码 -->
    <title>页面标题</title>    <!-- 浏览器标签页文字 -->
</head>
<body>
    <!-- 页面可见内容写在这里 -->
</body>
</html>
```

| 部分 | 说明 |
|------|------|
| `<!DOCTYPE html>` | 必须写在第一行，告诉浏览器用 HTML5 标准解析 |
| `<head>` | 元信息区：编码、标题、CSS引用、SEO 标签等，**不可见** |
| `<body>` | 内容区：所有**可见**的页面元素 |

## 2. 文本标签

### 2.1 标题 h1 ~ h6

| 标签 | 用途 | 惯例 |
|------|------|------|
| `<h1>` | 最高级标题 | 一个页面通常只用 **1 次** |
| `<h2>` | 二级标题 | 章节标题 |
| `<h3>` ~ `<h6>` | 更小标题 | 按层级嵌套使用 |

### 2.2 段落与换行

| 标签 | 效果 | 说明 |
|------|------|------|
| `<p>` | 段落 | 前后自动换行 + 留间距，**块级** |
| `<br>` | 换行 | 单纯换行不产生间距，**自闭合** |

### 2.3 文本格式化

| 标签 | 效果 | 有语义？ |
|------|------|-----------|
| `<strong>` | **加粗** | ✅ SEO/读屏器会识别为"重要内容" |
| `<b>` | **加粗** | ❌ 纯视觉 |
| `<em>` | *斜体* | ✅ 语义化强调 |
| `<i>` | *斜体* | ❌ 纯视觉 |
| `<mark>` | <mark>高亮</mark> | 黄色背景 |
| `<del>` | ~~删除线~~ | 表示删除的内容 |
| `<ins>` | <ins>下划线</ins> | 表示新增的内容 |
| `<sub>` | 下标 H<sub>2</sub>O | 化学式等 |
| `<sup>` | 上标 x<sup>2</sup> | 数学公式等 |

> **记忆诀窍**：有语义的优先用（strong > b，em > i），对 SEO 和读屏器更友好。

### 2.4 其他

| 标签 | 用途 |
|------|------|
| `<!-- 注释 -->` | 浏览器不显示，给自己/同事看，VS Code 快捷键 `Ctrl + /` |
| `<hr>` | 横线分隔，表示主题切换，自闭合 |

## 3. 链接 & 图片

### 3.1 超链接 `<a>`

```html
<a href="目标地址" target="_blank">显示的文字</a>
```

| 属性 | 值 | 说明 |
|------|-----|------|
| `href` | URL 或 `#id` | 目标地址 |
| `target="_blank"` | — | 新标签页打开 |
| `target="_self"` | — | 当前窗口打开（默认） |

**页面内锚点跳转**：目标元素设置 `id="xxx"`，链接写 `href="#xxx"`。

### 3.2 图片 `<img>`

```html
<img src="图片路径" alt="替代文字" width="200" height="100">
```

| 属性 | 必填 | 说明 |
|------|------|------|
| `src` | ✅ | 图片 URL 或本地路径 |
| `alt` | ✅ | 加载失败时显示，读屏器也会读 |
| `width` / `height` | 可选 | 宽高（像素） |

> `<img>` 是**自闭合标签**，没有 `</img>`。

## 4. 列表

### 4.1 无序列表 `<ul>`

```html
<ul>
    <li>项目一</li>
    <li>项目二</li>
</ul>
```

前面默认显示**圆点**，常用于导航菜单、功能列表。

### 4.2 有序列表 `<ol>`

```html
<ol>
    <li>第一步</li>
    <li>第二步</li>
</ol>
```

前面显示**数字序号**，常用于步骤、排名。

### 4.3 嵌套列表（⚠️ 易错）

```html
<!-- ✅ 正确：子 ul 放在 li 内部 -->
<ul>
    <li>前端
        <ul>
            <li>HTML</li>
            <li>CSS</li>
        </ul>
    </li>
</ul>

<!-- ❌ 错误：子 ul 放在 li 外面 -->
<ul>
    <li>前端</li>
    <ul><li>HTML</li></ul>  <!-- 这样不对！ -->
</ul>
```

## 5. 表格 `<table>`

### 5.1 结构

```html
<table border="1" cellpadding="8" cellspacing="0">
    <thead>              <!-- 表头区域 -->
        <tr>             <!-- 一行 (table row) -->
            <th>列名1</th>  <!-- 表头单元格，默认加粗居中 -->
            <th>列名2</th>
        </tr>
    </thead>
    <tbody>              <!-- 表体区域 -->
        <tr>
            <td>数据1</td>  <!-- 普通单元格 (table data) -->
            <td>数据2</td>
        </tr>
    </tbody>
</table>
```

### 5.2 合并单元格

| 属性 | 方向 | 示例 |
|------|------|------|
| `colspan="2"` | 横跨 2 列（左右合并） | `<td colspan="2">` |
| `rowspan="2"` | 竖跨 2 行（上下合并） | `<td rowspan="2">` |

### 5.3 ⚠️ 常见拼写错误

| 错误 | 正确 |
|------|------|
| `<tboyd>` | `<tbody>` |
| `<talbe>` | `<table>` |

## 6. 表单 `<form>`

### 6.1 表单容器

```html
<form action="#" method="get">
    <!-- 表单控件放这里 -->
</form>
```

### 6.2 常用表单控件

| 控件 | 代码 | 说明 |
|------|------|------|
| 文本框 | `<input type="text" placeholder="提示">` | 单行文本 |
| 密码框 | `<input type="password">` | 输入显示为 ● |
| 单选框 | `<input type="radio" name="组名">` | 同组 name 必须相同 |
| 复选框 | `<input type="checkbox">` | 可多选 |
| 下拉框 | `<select><option>选项</option></select>` | 点开选择 |
| 多行文本 | `<textarea rows="4" cols="40"></textarea>` | 大段文字 |
| 按钮 | `<button type="submit">提交</button>` | submit/reset/button |

### 6.3 `<label>` 标签

```html
<label for="email">邮箱：</label>
<input type="text" id="email">
```

`label` 的 `for` 关联 `input` 的 `id`，点击 label 文字会自动聚焦输入框。

## 7. 语义化标签

| 标签 | 用途 | 记忆 |
|------|------|------|
| `<header>` | 页头 / Logo / 标题 | 报纸报头 |
| `<nav>` | 导航链接 | 目录 |
| `<main>` | **唯一**主体内容 | 正文 |
| `<section>` | 内容区块 | 章节 |
| `<article>` | 独立内容 | 一篇博客 |
| `<aside>` | 侧边栏 | 边栏注释 |
| `<footer>` | 页脚 / 版权 | 报纸底栏 |
| `<div>` | 通用块容器（无语义） | 布局主力 |
| `<span>` | 通用行内容器（无语义） | 包裹小段文字 |

> **好处**：SEO 友好、读屏器友好、代码可读性好。
