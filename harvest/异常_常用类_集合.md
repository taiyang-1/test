## 一、异常处理（Exception）

### 为什么要有异常？
程序运行时出错（除零、数组越界、空指针）如果不处理，程序直接崩溃。用 try-catch 可以**捕获错误，给出提示，让程序继续跑**。

### try-catch-finally 结构

```java
try {
    // 可能出错的代码
    int result = a / b;
} catch (ArithmeticException e) {
    // 出错后执行的兜底代码
    System.out.println("除数不能为0");
} finally {
    // 无论是否出错，最后一定执行（释放资源用）
    System.out.println("计算结束");
}
```

### try-catch 执行流程

| 情况 | try | catch | finally |
|------|-----|-------|---------|
| 没出错 | 执行完 | 跳过 | 执行 |
| 出错了 | 出错行停住，跳 catch | 执行 | 执行 |
| try 里 return 了 | 执行到 return | 跳过 | **先 finally 再 return** |

### 多 catch

一个 try 可以跟多个 catch，处理不同类型的异常，**子类异常写前面，父类写后面**：

```java
try {
    int x = 10 / 0;
    String s = null;
    s.length();
} catch (ArithmeticException e) {   // 具体的先抓
    System.out.println("算术异常");
} catch (NullPointerException e) {
    System.out.println("空指针");
} catch (Exception e) {              // 兜底的放最后
    System.out.println("其他异常");
}
```

### try-catch 常用方法

| 方法 | 效果 |
|------|------|
| `e.getMessage()` | 获取异常简要信息 |
| `e.printStackTrace()` | 打印红色堆栈信息（调试用） |
| `e.toString()` | 异常类型 + 信息 |

## 二、包装类（Wrapper）

### 为什么要有包装类？
- 基本类型（int、double）**不是对象**，不能放进集合（ArrayList、HashMap）
- 基本类型**不能表示 null**（数据库查出来的空值没法存）
- 需要用 `Integer.parseInt()` 把**字符串转数字**

### 八种包装类对照

| 基本类型 | 包装类 | 常用场景 |
|----------|--------|----------|
| `byte` | `Byte` | 文件/网络原始字节 |
| `short` | `Short` | 数据库小整数 |
| `int` | `Integer` | **最常用**，集合存整数、字符串转数字 |
| `long` | `Long` | 时间戳、大数据 ID |
| `float` | `Float` | 精度要求不高的小数 |
| `double` | `Double` | 小数计算 |
| `char` | `Character` | 字符类型判断 |
| `boolean` | `Boolean` | 配置开关 |

### 核心操作（以 Integer 为例，其他套路一样）

| 方法 | 效果 | 示例 |
|------|------|------|
| `Integer.parseInt(s)` | String → int | `Integer.parseInt("123")` → `123` |
| `Integer.valueOf(s)` | String → Integer 对象 | `Integer.valueOf("123")` |
| `Integer.toString(n)` | int → String | `Integer.toString(456)` → `"456"` |
| `String.valueOf(n)` | 任意类型 → String | `String.valueOf(3.14)` → `"3.14"` |

### 自动装箱 / 自动拆箱

```java
Integer i = 100;     // 自动装箱：int → Integer（编译器自动加 valueOf）
int n = i;           // 自动拆箱：Integer → int（编译器自动加 intValue）
```

### parseInt vs valueOf

| 方法 | 返回值 | 能表示 null？ |
|------|--------|--------------|
| `Integer.parseInt("123")` | `int`（基本类型） | 不能 |
| `Integer.valueOf("123")` | `Integer`（对象） | 能，解析失败返回 null |

## 三、String 常用方法

### String 不可变
String 内容一旦创建**不能修改**，所有操作方法都是**返回新字符串**，原字符串不变。

### 常用方法速查

| 方法 | 效果 | 示例 |
|------|------|------|
| `length()` | 获取长度 | `"abc".length()` → `3` |
| `charAt(i)` | 取索引 i 的字符 | `"abc".charAt(1)` → `'b'` |
| `indexOf(s)` | 查子串首次出现位置 | `"abc".indexOf("b")` → `1` |
| `substring(a, b)` | 截取 [a, b) 子串 | `"hello".substring(1, 3)` → `"el"` |
| `trim()` | 去首尾空格 | `" a ".trim()` → `"a"` |
| `replace(a, b)` | 替换所有 a 为 b | `"aaa".replace("a","b")` → `"bbb"` |
| `split(d)` | 按分隔符拆分 | `"a,b,c".split(",")` → `["a","b","c"]` |
| `toUpperCase()` | 转大写 | `"hi".toUpperCase()` → `"HI"` |
| `toLowerCase()` | 转小写 | `"HI".toLowerCase()` → `"hi"` |
| `equals(s)` | 判等（比值不比地址） | `"a".equals("a")` → `true` |
| `contains(s)` | 是否包含子串 | `"java".contains("av")` → `true` |
| `startsWith(s)` | 是否以 s 开头 | `"java".startsWith("ja")` → `true` |
| `endsWith(s)` | 是否以 s 结尾 | `"java".endsWith("va")` → `true` |

### equals 和 == 的区别

```java
String a = "hello";
String b = new String("hello");

a == b          // false：== 比较内存地址，两个对象地址不同
a.equals(b)     // true：equals 比较内容，内容一样就 true
```

> **判断字符串内容相等永远用 equals，别用 ==**

## 四、StringBuilder

### 为什么不用 String + 拼接？
String 每次 `+` 都会**创建新对象**，旧的变垃圾。循环里 + 拼接 1 万次 = 创建 1 万个垃圾对象，又慢又占内存。

### StringBuilder 常用方法

| 方法 | 效果 |
|------|------|
| `new StringBuilder()` | 创建空的 |
| `append(s)` | 末尾追加 |
| `insert(i, s)` | 指定位置插入 |
| `delete(a, b)` | 删除 [a, b) 范围 |
| `reverse()` | 反转内容 |
| `toString()` | 转成 String |
| `length()` | 长度 |

### String vs StringBuilder 选择

| 场景 | 用哪个 |
|------|--------|
| 少量拼接（几条）、内容不变 | String |
| 循环拼接、频繁修改 | StringBuilder |

## 五、ArrayList（列表集合）

### 为什么不用数组？
数组长度**固定**，创建后不能改。ArrayList 长度**自动扩容**，增删一行代码搞定。

### 数组 vs ArrayList

| | 数组 | ArrayList |
|------|------|------|
| 长度 | 固定 | 自动变 |
| 增删 | 手写循环 | `add()` / `remove()` |
| 存基本类型 | 直接存 | 要包装成 Integer |
| 类型安全 | 运行时检查 | 泛型 `<String>` 编译时检查 |

### 常用方法（8 个核心）

| 方法 | 效果 | 示例 |
|------|------|------|
| `add(e)` | 末尾添加 | `list.add("张三")` |
| `add(i, e)` | 指定位置插入，后面元素后移 | `list.add(2, "插入")` |
| `get(i)` | 按索引取元素 | `list.get(0)` → `"张三"` |
| `set(i, e)` | 修改指定位置元素 | `list.set(0, "新值")` |
| `remove(i)` | 按索引删除，后面元素前移 | `list.remove(1)` |
| `remove(obj)` | 按值删除第一个匹配项 | `list.remove("张三")` |
| `size()` | 获取元素个数（不是容量） | `list.size()` → `5` |
| `contains(obj)` | 判断是否包含某元素 | `list.contains("张三")` → `true` |

### 三种遍历方式

| 方式 | 语法 | 适用场景 |
|------|------|----------|
| 普通 for | `for (int i = 0; i < list.size(); i++)` | 需要索引时 |
| 增强 for | `for (String s : list)` | 只读不删不改 |
| forEach | `list.forEach(item -> ...)` | 简洁打印 |

## 六、HashMap（键值对集合）

### 为什么要有 HashMap？
ArrayList 只能**按位置**获取（`get(3)`）。现实中有大量**按名字查询**的需求：学号查学生、省份查省会。HashMap 就是干这个的。

### 核心方法（8 个）

| 方法 | 效果 | 示例 |
|------|------|------|
| `put(k, v)` | 添加/更新（key 重复会覆盖） | `map.put("四川", "成都")` |
| `get(k)` | 根据 key 取值，无则返回 null | `map.get("四川")` → `"成都"` |
| `remove(k)` | 根据 key 删除键值对 | `map.remove("四川")` |
| `containsKey(k)` | 是否包含 key | `map.containsKey("四川")` → `true` |
| `containsValue(v)` | 是否包含 value | `map.containsValue("成都")` → `true` |
| `size()` | 键值对个数 | `map.size()` |
| `keySet()` | 返回所有 key 的 Set 集合 | 用于遍历 |
| `values()` | 返回所有 value 的 Collection | 用于遍历 |
| `entrySet()` | 返回所有键值对 Entry | 遍历时同时拿 key 和 value |

### 三种遍历方式

| 方式 | 写法 |
|------|------|
| keySet | `for (String k : map.keySet()) { map.get(k); }` |
| values | `for (String v : map.values()) { ... }` |
| entrySet（推荐） | `for (Map.Entry<String,String> e : map.entrySet()) { e.getKey(); e.getValue(); }` |

### HashMap 关键规则

- **key 不能重复**：put 同一个 key 新值会**覆盖**旧值
- **一个 key 只对应一个 value**
- key 可以为 null（最多一个），value 可以为 null（允许多个）
- **无序**：遍历顺序和插入顺序不一定一致

## 六点五、ArrayList vs HashMap 

| | ArrayList | HashMap |
|------|------|------|
| 像什么 | 一排储物柜，按编号找 | 一本字典，按词条名找 |
| 存什么 | 只存值 `list.add("张三")` | 存键+值 `map.put("张三", 85)` |
| 怎么取 | 用下标 `list.get(0)` | 用 key `map.get("张三")` |
| 怎么删 | `list.remove(0)` — 按下标 | `map.remove("张三")` — 按 key |
| 怎么改 | `list.set(0, "李四")` | `map.put("张三", 90)` ← 同一个 put |
| 有没有 | `list.contains("张三")` | `map.containsKey("张三")` |
| 大小 | `list.size()` | `map.size()` |
| 有没有下标 | ✅ `get(0)` | ❌ 没有下标概念 |

**核心记忆**：ArrayList 靠 int 下标，HashMap 靠任意类型的 key。碰到"按XX查XX"就往 HashMap 想。

## 七、HashSet / TreeSet（Set 集合）

### Set 的特点
- **不允许重复元素**
- HashSet **无序**，TreeSet **自动排序**

### HashSet 常用方法

| 方法 | 效果 |
|------|------|
| `add(e)` | 添加元素，重复则忽略并返回 false |
| `remove(e)` | 删除元素 |
| `contains(e)` | 判断是否包含 |
| `size()` | 元素个数 |
| `isEmpty()` | 是否为空 |
| `clear()` | 清空 |

### HashSet 三种遍历

| 方式 | 写法 |
|------|------|
| 增强 for | `for (String s : set) { ... }` |
| 迭代器 | `Iterator<String> it = set.iterator(); while(it.hasNext()){ it.next(); }` |
| forEach | `set.forEach(s -> System.out.println(s));` |

### TreeSet 额外方法

| 方法 | 效果 |
|------|------|
| `first()` | 最小元素 |
| `last()` | 最大元素 |
| `higher(e)` | 比 e 大的最小元素 |
| `lower(e)` | 比 e 小的最大元素 |

### TreeSet 自定义排序

```java
// 方式 1：构造器传 Comparator（优先级更高）
TreeSet<String> ts = new TreeSet<>(new Comparator<String>() {
    @Override
    public int compare(String o1, String o2) {
        return o1.length() - o2.length();  // 按长度升序
    }
});

// 方式 2：让元素类实现 Comparable 接口（自然排序）
class Student implements Comparable<Student> {
    @Override
    public int compareTo(Student o) {
        return this.score - o.score;
    }
}
```

### 集合运算（交集、并集、差集）

```java
Set<Integer> a = new HashSet<>();
Set<Integer> b = new HashSet<>();

Set<Integer> union = new HashSet<>(a);   // 并集
union.addAll(b);

Set<Integer> inter = new HashSet<>(a);   // 交集
inter.retainAll(b);

Set<Integer> diff = new HashSet<>(a);    // 差集 A - B
diff.removeAll(b);
```

### ArrayList vs HashSet 选择

| 场景 | 用什么 |
|------|--------|
| 允许重复、需要索引 | ArrayList |
| 必须去重 | HashSet |
| 去重 + 需要排序 | TreeSet |

## 九、自定义异常 + throw / throws

### throw vs throws

| 关键字 | 位置 | 作用 |
|------|------|------|
| `throw` | 方法**内部** | 手动抛出异常对象 |
| `throws` | 方法**签名** | 声明"这个方法可能抛异常，调用方自己处理" |

```java
// 定义自定义异常
public class ScoreException extends Exception {
    public ScoreException(String message) {
        super(message);  // 把消息传给父类 Exception
    }
}

// 使用
public void addScore(String name, int score) throws ScoreException {  // ← throws：声明
    if (score < 0 || score > 100) {
        throw new ScoreException("分数不合法");  // ← throw：抛出
    }
    scores.put(name, score);
}
```

### 调用方如何处理 throws 方法

| 方式 | 写法 | 何时用 |
|------|------|--------|
| try-catch 兜住 | `try { ... } catch(ScoreException e) { ... }` | 当前方法自己能处理 |
| 继续往外抛 | `public void foo() throws ScoreException { ... }` | 自己不处理，丢给上层 |
