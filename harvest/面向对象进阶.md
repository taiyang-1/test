
## 1. 继承（Inheritance）

- `子类 extends 父类`，Java 单继承
- `super()` 调用父类构造器，必须在子类构造器第一行；不写默认调 `super()`（无参）
- `@Override` 重写父类方法（推荐写，编译器帮检查）
- `private` 成员子类不能直接访问，通过 getter/setter
- 权限修饰符：`private` → 默认（同包） → `protected`（同包+子类） → `public`

## 2. 多态（Polymorphism）

- **父类引用指向子类对象**：`Person p = new Student()`
- 三个条件：继承 + 方法重写 + 父类引用指向子类对象
- **编译看左边，运行看右边**：左边决定能调什么方法，右边决定实际跑哪个版本
- `instanceof` + 向下转型：`if (p instanceof Student) { Student s = (Student) p; }`

## 3. 抽象类（Abstract Class）

- `abstract class` 不能直接 `new`
- `abstract` 方法没有方法体，子类必须重写
- 有抽象方法的类必须是抽象类
- 抽象类可以有构造器、普通方法、成员变量

## 4. 接口（Interface）

- 接口 = 纯抽象规范，方法默认 `public abstract`
- 类单继承，接口多实现：`class A implements B, C, D`
- 接口多态：`接口名[] arr` 可以存所有实现了该接口的对象
- JDK8+ 可有 `default` 方法

| 对比 | 抽象类 | 接口 |
|------|--------|------|
| 关键字 | abstract class | interface |
| 继承/实现 | 单继承 extends | 多实现 implements |
| 构造器 | 有 | 没有 |
| 成员变量 | 可以 | 只能常量 |
| 方法 | 抽象+普通 | 抽象（+default） |

## 5. final

- `final class` → 不能被继承
- `final 方法` → 子类不能重写
- `final 变量` → 常量，初始化后不能改（配合 `static` 做类常量）

## 6. 匿名内部类

```java
new 接口名() {
    @Override
    public 返回值 方法名() { ... }
};
```
